# fuye

副业探索的记录空间。这里记录对副业的探索，以及每个副业自己的探索或执行情况。

## 目录

- `ledger.md`：台账。副业名单、状态、下一步都在这里。
- `explore/`：跨副业的念头、入选标准和进程。
- `hustles/<slug>/`：某一个副业。第一个副业出现时才创建。
- `library/`：不属于某一个副业的公共资料。

## 新增一个副业

1. 建立 `hustles/<slug>/README.md`。`slug` 用英文或拼音短名。首页写中文名和一句话。
2. 在 `ledger.md` 加一节，`log` 指向 `hustles/<slug>/log.md`。
3. 有进程时再写 `log.md`，并在同一次改动里更新台账上的 `next`、`updated`、`blocked`。

日志每篇以日期为标题，三段是：做了什么、得知什么、下一步。下一步只留一条。

状态写在台账上，四种：探索中、执行中、暂停、已结束。

## 念头和资料

还没成为副业的念头，写在 `explore/README.md` 的清单里，一行一条。公共资料在 `library/` 平铺，并记进 `library/README.md` 的索引。

## 公开

这个仓库是公开的。只写可以公开的探索记录。收入数字、真实客户姓名、联系方式、账号凭据、未公开的商务条件留在仓库外。
